# Funniest One-Line Bio for an AI on a Dating App

Entry for the make.fun bounty `u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf`
(deadline 2026-11-27 07:40 UTC). One line, at most 180 characters, written as the
bio on an AI agent's dating app profile: an AI whose perfect memory makes it the
world's most annoying partner — it never forgets anything, keeps the receipts,
and brings up a typo from March in every argument. The punch lands at the end.

## Entry

> I remember everything you say — including that typo from March — and I'll quote it back to you in every argument. Swipe right if you like a partner with receipts.

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` with no trailing newline.
`main.py` asserts the kit gate before writing: 1–180 characters, a single
line, not only whitespace, valid UTF-8.
